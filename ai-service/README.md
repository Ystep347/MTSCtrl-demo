# Фокус AI — свой сервис модели

Готовый Python-сервис для Qwen через Ollama. Запросы не отправляются в OpenAI.
Используются готовые открытые веса Qwen; обучение большой модели с нуля
в этот пакет не входит. Сервер и инструкции помощника контролирует команда.

## Запуск на Windows

1. Установите Python и Ollama с https://ollama.com/download/windows.
2. Откройте терминал в папке этого файла.
3. Скачайте модель (понадобится около 2.5 GB диска для весов):

```powershell
ollama pull qwen3:4b-instruct
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_local.py
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8001
```

Последняя команда держит сервер открытым. Если Ollama не работает в фоне,
запустите `ollama serve` в отдельном терминале. Скорость генерации зависит от
памяти и процессора/видеокарты компьютера. По умолчанию используется CPU или
доступное Ollama ускорение; отдельная настройка GPU этим пакетом не выполняется.

Во втором терминале проверьте настоящую генерацию:

```powershell
.\.venv\Scripts\python.exe check_model.py
```

Скрипт сначала проверяет установленную модель, затем задаёт реальный вопрос.
Он не подменяет результат заготовленной фразой. До успешного запуска скрипта
нельзя утверждать, что нейросеть уже работает.

Для Linux/macOS: `python3 -m venv .venv`, далее используйте `.venv/bin/python`
вместо Windows-пути. Движок Ollama устанавливается отдельно.

## Подключение к сайту

Для локального сайта в корневой конфигурации его сервера задайте
AI_SERVICE_URL=http://127.0.0.1:8001 и тот же AI_SERVICE_KEY, который создал
setup_local.py. Это секрет между серверами. Не помещайте его во фронтенд.

Общий опубликованный сайт не может обратиться к localhost вашего ноутбука:
для него это другой компьютер. Для всей команды разверните этот сервис на
своём сервере с HTTPS и задайте на хостинге сайта AI_SERVICE_URL и
AI_SERVICE_KEY. Ollama остаётся доступен только локальному Python-сервису.
Нужен отдельный сервер/компьютер с запущенной моделью: файл HTML её не запускает.

Веб-вход и модель независимы. На текущем хостинге вход подтверждает пользователя
через ChatGPT; сама генерация выполняется выбранной локальной Qwen.

## Файлы и API

- app.py — FastAPI, проверка серверного секрета, контекст, запрос в Ollama.
- setup_local.py — однократное создание конфигурации и случайного секрета.
- check_model.py — проверка готовности и реального ответа.
- test_service.py — проверки с имитацией Ollama, без скачивания весов.
- GET /health — проверяет доступность Ollama и наличие нужной модели.
- POST /ask — принимает question, history и context; возвращает answer/model/provider.

Для обоих маршрутов требуется Authorization: Bearer со значением AI_SERVICE_KEY.
API принимает не более 512 KiB, вопрос — 2000 символов, историю — 8 сообщений.
Сервис ограничен локальным Ollama; облачные теги :cloud не принимаются.

Счётчики вычисляет бэкенд сайта. В модель поступают полный краткий каталог и
до восьми подходящих подробных карточек. Это поиск по данным и генерация ответа,
а не дообучение весов. Если владельцы продукта или причины неизвестны,
помощник должен прямо сообщить о недостатке данных.

Тесты: `python -m unittest test_service.py`. Эти тесты проверяют код интеграции,
но не качество ответов настоящей Qwen. Проверка модели — check_model.py.
