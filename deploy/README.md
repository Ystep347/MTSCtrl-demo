# МТС Фокус · готовый сервер

Распакуйте ZIP полностью в папку, куда у вас есть право записи. Внутри уже есть сайт, учебная выгрузка на 44 инцидента и миграции SQLite. Выберите один способ запуска.

## Запуск с Node.js

На сервере нужен Node.js 24 или новее со встроенным модулем `node:sqlite`. Используйте сборку Node.js для своей ОС и процессора. На Windows можно дважды нажать `start.cmd`. На Windows, Linux и macOS можно открыть терминал в папке с `start.mjs` и выполнить:

```sh
node start.mjs
```

Сайт работает, пока запущен процесс. Остановить его можно сочетанием Ctrl+C. Сборка проекта, npm и установка пакетов для запуска не требуются.

## Запуск с Docker

Если на устройстве уже есть Docker с Linux-контейнерами и Compose, выполните в распакованной папке:

```sh
docker compose up -d
```

При первом запуске Docker скачает образ Node.js. Для просмотра журнала выполните `docker compose logs -f`, для остановки — `docker compose down`. При запущенном Docker контейнер автоматически поднимается после перезапуска устройства, если его не остановили вручную.

## Как подключиться

На сервере откройте **http://localhost:4173**. Для гостевого просмотра с другого компьютера, телефона или видеостены в той же сети откройте `http://IP-СЕРВЕРА:4173/?guest=1`. Адрес видеостены — `/?guest=1&screen=wallboard`. Достаточно браузера. При обычном запуске сервер выводит доступные адреса. При запуске в Docker используйте сетевой адрес хоста. Для доступа из сети входящий TCP-порт 4173 должен быть доступен на сервере.

Если порт занят, создайте файл `.env` рядом со `start.mjs`, добавьте `PORT=8080` и повторите запуск. При использовании Docker снова выполните `docker compose up -d`. Для просмотра только на сервере при запуске с Node.js можно задать `HOST=127.0.0.1`.

## Общие учётные записи и HTTPS

На самом сервере парольный вход работает через `http://localhost`. При входе удалённых пользователей браузеру нужен HTTPS для cookie сеанса. Гостевой режим по HTTP доступен и без сертификата. Гостевые действия хранятся в браузере, работа под учётной записью — на сервере.

- **Прямой HTTPS.** Поместите сертификат для имени сервера и его приватный ключ в каталог `certs`. В `.env` укажите `TLS_CERT_FILE=certs/fullchain.pem` и `TLS_KEY_FILE=certs/privkey.pem`. Перезапустите сервер и откройте `https://имя-сервера:4173`. Клиентские устройства должны доверять сертификату.
- **За существующим HTTPS-прокси.** Направьте запросы на HTTP-порт приложения. В `.env` задайте внешний адрес, например `PUBLIC_ORIGIN=https://focus.example.org`, и перезапустите приложение. Если внешний порт нестандартный, включите его в адрес.

## Данные и обновление версии

SQLite создаётся автоматически в `local-data/incidents.sqlite`. Здесь хранятся общие аккаунты, назначения, история и импортированные версии. Исходный файл для автоматического обновления — `data/incidents.json`. Docker сохраняет эти файлы в распакованной папке на хосте.

Для обновления остановите сервер, распакуйте новый архив в отдельную папку и перенесите туда свой каталог `local-data`, свой `data/incidents.json`, а также `.env` и сертификаты, если они использовались. Запустите новую версию. Миграции применятся автоматически. Для резервной копии сохраните те же файлы после остановки сервера.

Для выдачи прав редактора сначала зарегистрируйте пользователя. Затем выполните на сервере `node scripts/grant-local-editor.mjs ваш-логин`. Для Docker используйте `docker compose exec focus node scripts/grant-local-editor.mjs ваш-логин`.

По умолчанию доступны помощник по правилам и учебный SimpleOne. Ключи Яндекса и параметры рабочего SimpleOne можно задать в `.env` по шаблону `.env.example`. Сохраните секреты только на своём сервере. [Документация проекта](https://github.com/Ystep347/MTSCtrl-demo#readme)
