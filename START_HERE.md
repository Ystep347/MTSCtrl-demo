# МТС Фокус — начать здесь

Срез проекта: 21 ноября 2026, v17 «Подсказки координатору и объяснимое следующее действие».
Это исходники работающего прототипа, а не законченная корпоративная система.

## Запустить на своём компьютере

1. Клонируйте репозиторий или распакуйте скачанный архив. Откройте терминал
   в папке, содержащей `package.json`.
2. Установите Node.js 24 или новее. Проверенный runtime: 24.22.3. Python и Docker для запуска не нужны.
3. Для запуска из репозитория установите зависимости и соберите проект.

```sh
npm ci
npm run build
npm run dev
```

Откройте http://localhost:4173. Не открывайте `web/index.html` двойным кликом:
странице нужны серверные `/api/*` и JavaScript-модули.
На Windows команды одинаковые: PowerShell, терминал VS Code или командная строка.
Если порт занят, настройте `PORT=4174` в `.env` и перезапустите сервер.
В переносном архиве с готовой папкой `dist/` для просмотра достаточно `npm run dev`.

## Проверить без внешних сервисов

По умолчанию показана явно помеченная симуляция 44 телеком-инцидентов МТС.
Исполнители и бизнес-атрибуты сохранены. Кнопка «Показать исходные данные»
возвращает выгрузку организаторов. Порядок живой проверки — в DEMO_CHECKLIST.md.

Гостю доступны дашборд, четыре группы, поиск, фильтры, карточки, графики,
общий экран, дневная/ночная темы и журнал. `data/incidents.json` перечитывается
сервером при запросе, браузер проверяет обновления каждые 5 секунд.
Автоматическая проверка `npm run test:local` использует отдельные временные
файлы и базу; исходные данные и опубликованный сайт она не меняет.

## Войти без внешнего аккаунта

Откройте `/login`, выберите «Создать аккаунт», укажите имя, логин и пароль.
Это самостоятельная регистрация в Фокусе. Новому пользователю доступна роль
координатора: просмотр и вопросы помощнику. Общих паролей в архиве нет.
Аккаунты и сеансы сохраняются в базе после перезапуска сервера.

Для локального редактора сначала создайте свой аккаунт, затем в терминале:

```sh
npm run auth:editor -- ВАШ_ЛОГИН
```

После обновления страницы появятся импорт, «Доступ команды» и «Подключение ИИ».
На опубликованном сайте первый редактор выдаёт права по AUTHENTICATION.md.
Для подготовки локальной формы ИИ выполните `npm run ai:prepare`, перезапустите
сервер и откройте `/ai-settings` под редактором. Команда создаёт только ключ
шифрования настроек, а не API-ключ Яндекса. Сам ключ провайдера и ID каталога
нужно получить в облачном аккаунте команды. Без них работает анализ по правилам.
Подробнее — AI_CONNECTION.md.

## Передать в другой чат

Загрузите **весь ZIP** и отправьте:

> Продолжаем разработку МТС Фокус. Распакуй архив, сначала прочитай
> START_HERE.md, NEXT_CHAT.md, IMPLEMENTATION_STATUS.md и материалы/МТС.pdf.
> Проверь сборку и тесты. Продолжай с первого незавершённого пункта NEXT_CHAT.md.
> Сохрани исходный формат выгрузки и текущий дизайн. Не выдавай деморежим за ИИ.

Контекст, задачи и инструкции есть в архиве. Чужой чат не получает автоматически
историю переписки, доступ к опубликованному сайту, ключи, аккаунты, сеансы и данные его рабочей базы.
Локально он сможет начать с этого среза; обновление существующего сайта потребует
доступа владельца. Не создавайте новый сайт вместо существующего без решения команды.
