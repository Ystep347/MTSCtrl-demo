# Идеи из mts_idei.docx и текущая реализация

Проверено по исходникам 21.11.2026. Документ содержит предложения, а не готовые функции.

| Идея | Что есть | Следующий шаг |
|---|---|---|
| Team Load | Диаграмма количества незавершённых записей по командам с разделением приоритетов и исследования | Согласовать веса; не выдавать число карточек за занятость сотрудников |
| Incident DNA | В нормализации доступны признаки записей; карты причинных связей нет | Нужны идентификаторы связанных записей; булевы признаки не доказывают связь между двумя ID |
| Impact Radar | Отдельного поиска кластеров нет | Настроить признаки, временное окно и подавление ложных совпадений |
| Next Best Action | На основном экране: следующее действие с основанием по правилам текущей карточки; lib/coordinator-insights.mjs | Подключить справочник владельцев для обоснованной рекомендации конкретной команды |
| Service Recovery Map | Сводные показатели по продукту есть, подтверждённой карты восстановления сервисов нет | Согласовать модель сервисов и обработку противоречащих записей |
| Blind Spot | На основном экране: раскрываемый список «Что проверить координатору» с переходами; отсутствующие команда/исполнитель/срок, передача и исследование | Для выявления долгого отсутствия изменений нужна надёжная история и согласованный порог |
| Focus Impact | Подтверждённой оценки последствий нет | Определить реальные признаки влияния без выдуманного числа пользователей |
| Similar Cases | Поиск успешных прецедентов не реализован | Нужны правила сходства и подтверждённый исход; solution сам по себе не доказывает успех |
| Incident Replay | Есть общий журнал и учебная перемотка в концепции Pulse | Построить просмотр сохранённых реальных версий; не выдавать учебные шаги за историю |

Приоритет NEXT_CHAT.md сохраняется: настоящая генерация Яндекса, согласование
перехода ITSM и прогон защиты. В v17 выполнена базовая версия Blind Spot и Next Best Action; остальные предложения не заявлены готовыми.
